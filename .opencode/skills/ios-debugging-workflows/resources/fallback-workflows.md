# Fallback Workflows

When LLDB or Xcode tooling cannot attach or inspect, switch to fallback strategies.

## Screenshot-based inspection
- Capture key UI states or error dialogs.
- Compare before/after states across steps.

## Recognition and extraction
- Use text recognition on screenshots for labels or error strings.
- Identify UI element positions and state changes.

## macOS control automation
- Script repeatable input flows to reproduce issues.
- Use automation to drive UI and gather repeatable evidence.
